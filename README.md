# Eloria - 액세서리 전문 이커머스 웹사이트

## 프로젝트 개요

**Eloria**는 20~30대 여성을 타겟으로 한 액세서리 전문 이커머스 웹사이트입니다.  
사용자 친화적인 UI 구성과 명확한 정보 전달을 통해 쾌적한 쇼핑 경험을 제공하는 것을 목표로 하였으며,  
2주간의 프로젝트 기간 동안 핵심 페이지 구성과 데이터 흐름 중심의 구조 설계를 진행하였습니다.

- **진행 기간**: 2024.08.21 ~ 2024.09.03 (2주)
- **참여 인원**: 3명 (Front1, Front2, Back)
- **기술 스택**: React, JavaScript, HTML/CSS, Node.js, PostgreSQL

---

## 🛠 핵심 기능 요약

| 분류 | 주요 기능 |
|------|-----------|
| 회원 기능 | 회원가입, 로그인 (일반 / 구글 OAuth), 로그아웃 |
| 상품 기능 | 상품 목록 조회, 상품 상세 페이지, 필터 기능 |
| 장바구니 기능 | 장바구니 담기 / 삭제, 로그인 시 접근 가능 |
| 주문 처리 | 주문 완료 페이지 및 구매 내역 확인 기능 |
| 데이터 관리 | 사용자 및 상품 데이터베이스 테이블 생성 및 연동 |

## 회고 및 느낀 점

단기간 프로젝트였지만, 이커머스 사이트의 필수적인 페이지를 구현함으로써 
각 기능별 흐름과 사용자 경험을 고려한 UI 구성에 집중했습니다.  
전체적인 시각 구조와 인터페이스 요소를 명확히 설계함으로써 팀 전체의 작업 효율을 높였고,  
프로젝트 간 협업 구조 속에서 컴포넌트 기반 개발 방식에 대한 실무 감각을 익힐 수 있었습니다.

또한 팀장으로서 서로 개발 속도가 달랐던 팀원 간의 진행 상황을 조율하고,  
과도한 분량 편차 없이 전체 일정 내에 기능 구현을 완료할 수 있도록 **협업을 적극 도모**했습니다.  
**기획–디자인–프론트 흐름까지 책임감 있게 이끌었던 경험**이 이번 프로젝트에서 뜻깊은 배움으로 남았습니다.
